# Перед приёмом — проверь!

Демонстрационный образовательный прототип по осознанному применению БАД.

**Не является медицинской диагностикой или полной проверкой лекарственных взаимодействий.** В учебной базе разобраны три примера. До практического использования требуется профессиональная проверка содержания.

## Сайт

Статический HTML/CSS/JavaScript. Откройте `index.html` локально или разместите файлы в корне репозитория с GitHub Pages.

Пользовательские ответы не отправляются на сервер и не сохраняются между сеансами. Сохранение памятки осуществляется локально.

## Источники

Русскоязычные материалы (Роспотребнадзор, MSD, инструкции) приведены внутри учебных модулей первыми, далее ссылки на научные и международные справочники.

## Об авторстве

Это демонстрационный прототип, программирование выполнено с применением генеративного ИИ. При использовании в конкурсных материалах учитывайте условия об авторстве и разрешённом применении ИИ.
